# NebulaStrike（星云突袭）

一款完全**离线**的 Android 街机太空射击游戏。零第三方依赖 —— 纯 Java 基于 Android
框架（`SurfaceView` + `Canvas`）实现，任何能跑 Android Studio 的环境都能构建，
APK 体积约 100 KB。

## 玩法
- **竖屏 + 浮动摇杆**：按住屏幕**任意位置**滑动，飞船按手指相对位移移动
  （MOBA/王者式操控，手指不遮挡飞机，松手即停，暂停自动冻结），右下角炸弹圆键，自动开火
  - **跟手优化**：指数逼近 + 2400 单位/秒上限，1px 级小位移一帧吸附到位；
    扫掠碰撞检测，高速甩动也不会瞬移穿过敌机/敌弹
- 迎击**二十二种敌机**：无人机（drone）、织机（weaver）、猎手（hunter）、坦克（tank）、
  **自杀机**（俯冲加速，解体时散出一圈碎片）、**分裂舱**（击毁后裂成两架无人机）、
  **医疗艇**（为周边友舰与 Boss 回血，优先点杀目标）、**狙击塔**（悬停预警后射出高速瞄准弹）、
  **布雷艇**（沿路抛下会呼吸报警的水雷，封锁走位通道）、**航母**（悬停期间持续放出无人机僚机）、
  **盾卫**（正面带 6 点护盾气泡，实弹全被挡下，只有穿透光束与弹跳弹绕得过去）、
  **伪装者**（套着道具外壳俯冲，靠眼力识破）、**磁暴艇**（中场悬停，磁场掰弯直射弹）、
  **集群蜂后**（边飞边产幼机，击杀她幼机全崩）、
  **冲撞者**（亮出落点预警线后沿直线俯冲，撞停硬直 1.4 秒、硬直期受击双倍）、
  **相位者**（按固定节拍相位化，0.7 秒无敌穿弹，重新实体化的瞬间受击双倍）、
  **追猎者**（悬停在中场横向跟船，双发追踪弹；转向率与寿命都有限，横移或冲刺就能甩掉）、
  **缚网者**（中场定幅摆渡，抛下缓慢网弹：命中不扣命，但速度降到 45%、封锁冲刺 2 秒，
  网弹可以点掉）、**螺旋炮台**（高位悬停，三臂螺旋连吐 9 拍，缺口随旋臂移动）、
  **切割者**（锁定一列后切下贯穿全场的竖光柱，点弹 / 弹反 / 反射都挡不住，只能让开）、
  **枢链者**（成对登场，两者之间拉起电弧锁链；充能后一起下扫，整条线都会灼伤，
  先拆掉任意一端就断链），按存活时间逐级登场，还会排成 V 字编队来袭
- **精英词缀**：中后期敌机有小概率镀上琥珀光环（血量 ×2.6、必掉道具），
  优先集火它就能稳定补一轮装备；精英率随难度档位缩放
- **突袭奖励波**：定期从屏幕上方压进一小队护航敌机，中央掉一枚金色奖励（BONUS）；
  清空这波敌机、敢上去捡就有大量分数 + 双倍分数 + 随机武器，同时清除全场敌弹
- **局内祭坛**：场上定期落下符文法阵，中央符文预告赐福（军械 / 生机 / 守护 / 财宝）。
  打它的核心或站进光环吸弹都能充能，充满即爆发；不理它则安静熄灭，不带来任何惩罚
- **赏金猎杀**：开局约 22 秒起，系统会把场上一艘现役重甲直接圈成**悬赏目标**
  （不额外刷怪、不挤占敌机池）：头顶金色菱形 + 16 秒倒计时环，目标加厚血量。
  限时击毁即兑现，连杀越高赏金越厚，并且每单**保底掉一件道具**（单数给武器、双数给火力）；
  目标脱逃只断连杀，不扣分也不扣命
- **分数奖励生命**：每跨过 **5 000 / 20 000 / 45 000 / 80 000 …**（5 000 × 档号²）
  就发一条命，分数条下方常驻下一档进度；命数满时折成炸弹，炸弹也满再折
  **500 分**——跨过阈值永远不会"什么都没拿到"
- **道具连携**：两套系统同时在线时自动点亮一层额外加成，右侧 HUD 出现金色角标，
  底部弹一条说明；任意一件过期立刻收回，**不替换、不削弱**任何已有道具：
  - **镜盾**（反射护罩 + 护盾）：反射充能 6 → 3.75 秒，弹回去的敌弹伤害 +1
  - **三叉戟**（散射 + 火力 ≥2）：散射弹获得穿透，正对密集编队时收益最高
  - **编队**（僚机 + 轨道球）：僚机射速 +30%，轨道球伤害 +1
  - **过载链**（速射 + 擦弹过载）：射击冷却再乘 0.62
  - **导电**（电弧炮 + 弹跳弹）：电弧连锁跳跃 +1
- **特化遭遇保底**：五种特化舰型（以及它们那套反制玩法）不再靠运气露面——过了各自的
  解锁窗口，只要场上缺哪一型就补一艘；敌机池被普通刷新占满时每 0.25 秒再抢一次位置，
  同型不叠两艘（不会出现两位蜂后互相铺幼机）。首次登场拉一条"新敌舰"介绍横幅，
  每种存档只弹一次，之后交给图鉴。伪装者的登场**故意不带任何音效与震动**——
  有提示就能靠听识破，"看字母换没换"这个玩法当场作废
- **二十四种掉落道具**（旋转六边形 + 脉冲光环 + 闪烁描边，与敌机明确区分；接近时磁吸捕获，
  光环加速闪烁提示可收集）：
  - **武器类**：散射 W / 追踪导弹 M（掉率提到 14%）/ **穿透激光 L** / **弹跳弹 N** /
    **电弧炮 AC**（掉率 2%）/ **回旋镖 BM**（掉率 1.5%）/ **锁定激光 LK**（掉率 1%）——
    武器全部**叠加持有**，各自独立射速、互不覆盖；同类武器可叠 3 层
    （扇形更宽 / 激光束更多 / 导弹齐射更密 / 橡胶球更多 / 电弧弹数与跳数更多 /
    回旋镖更多 / 锁定目标数更多）；
    **基础机炮常驻**，捡到任何道具都只多一路火力，绝不会变弱
  - **电弧炮 ARC**：弹体伤害 2，命中后从弹着点向 260 半径内最近的敌机 / Boss 部件连续跳跃，
    每跳 1 点伤害；相位中的敌机不参与连锁，跳跃会直接找到后方的实体目标
  - **回旋镖 BM**：伤害 3 的穿透圆盘，向上抛出去、0.62 秒后顶点折返，
    回程沿发射线扫回来——同一架敌机去程与回程各结算一次，等于一条竖线上的双程火力；
    回程还会顺手切掉路径上的敌弹。飞得太远会自己回收，不会占住弹池
  - **锁定激光 LK**：不占正前方弹道——每次开火自动点名最近的 2 个敌机 / Boss 部件，
    从屏幕顶端各砸下一道伤害 4 的贯穿光柱；叠层最多同时锁定 4 个目标，光柱沿途
    还能顺手串掉同一列上的敌机。落点会闪一圈收缩的锁定环，混战时也看得清打到了谁
  - **融合武器**（不掉落、纯奖励）：同时持有两种基础武器自动解锁第三路火力 ——
    SPREAD+LASER=**LANCE** 宽穿透长枪、SPREAD+MISSILE=**CLUSTER** 集束弹（命中炸开破片）、
    LASER+MISSILE=**SWARM** 追踪蜂群；融合不替换任何原有武器，原料耗尽才一并消失
  - **火力等级 P**：雷电式成长——弹道数量随等级 1→3 扩展，永久生效，坠机降 1 级，满级折算 300 分
  - **功能类**：护盾 S（可叠 2 层，每层挡一次伤害）/ 炸弹 B / 速射 R（8 秒射速翻倍）/
    双倍分数 ×2 / 生命 +（上限 4）；重复拾取延长时间，最多延长到基础时长的 2 倍
  - **僚机 D**：14 秒内两翼无人机自动交替开火；**缓时 T**：6 秒内敌机、敌弹与 Boss 降至 45% 速度
  - **轨道球 O**：10 秒内三颗能量球环绕飞船，擦除敌弹并持续撞击敌机；
    **连锁闪电 Z**：拾取瞬间从飞船向上逐级放电，命中最近的数个目标
  - **新星 V**：拾取瞬间清光全场敌弹，并对所有敌机与 Boss 部件来一次范围伤害，
    冲击波从飞船向外扩散；**纳米 X**：12 秒内每 3.5 秒自动补一层护盾；
    **炮台 U**：在拾取位置部署一座自动炮台（3 座为上限），三向齐射 16 秒、随战场缓慢下移，
    会替飞船吃掉敌弹与撞击，满员时折算 250 分；
    **重力井 GV**（掉率 2.5%，同屏最多 2 口）：在飞船上方部署一口吸弹黑洞，330 半径内的
    敌弹被拉向井口并吞下（每发 +3 分、补少量擦弹槽），库存满 12 发或到期时朝上方喷还成
    伤害 2 的实弹——正好越过点弹幕门槛，吸到的敌弹反过来变成自己的截弹火力；满员时折算 250 分
    **反射护罩 RF**（掉率 1.6%，最多 2 层）：命中飞船的那一发敌弹被原路翻面成伤害 2 的友军
    子弹，层数不消耗、只进入 6 秒充能；两层各自独立计时，叠满后折算 200 分
    **诱饵浮标 DC**（掉率 1.5%）：在飞船上方投下一个 9 秒的全息诱饵——
    追猎 / 狙击 / 追猎者 / 缚网 / 相位这五种瞄准弹改为瞄它；170 半径内的敌弹被拉过去，
    贴脸 12 发吃满或到期爆散，清掉 190 半径的弹幕并给圈内敌机 2 点伤害，
    不替玩家挡撞击，切割者 / 旋翼者的光束也不受它影响
- **难度档位**（设置面板三段选择器，持久化）：**休闲** 道具×1.45、掉命不掉装备、
  重生保护 4 秒、得分×0.75；**标准** 与历史版本数值完全一致，掉命降 1 级火力；
  **硬核** 敌机更快、道具更稀、精英更多、掉命清空特殊武器/圣物/炮台/重力井并把终极槽砍半、得分×1.5
- **重生保护**：阵亡后按难度获得 1.4~4 秒无敌，飞船罩在护盾气泡里并倒计时，
  同时以自身为圆心清掉一圈敌弹、重置所有武器冷却——落地就能开火，不再"落地成盒"
- **Boss 圣物**：每击败一只 Boss 随机继承它一种能力，永久生效到本局结束，
  HUD 右上角显示徽章、获得时拉横幅：光束核心（自动射出宽穿透光束）、永恒僚机（僚机不再到期，
  双翼各多一发）、镜像枪（基础炮追加两路 25° 镜像弹）、圣盾外壳（护盾上限 +1 且定期补层）、
  虹吸矩阵（擦弹同时给冲刺充能）、过载核心（过载时长翻倍、火力再 +1）、
  **相位核心**（冲刺充能 ×1.7，冲刺起步释放清弹冲击波）、
  **赏金执照**（赏金连杀上限 6→9、得分 ×1.5、脱逃只掉一连）；
  八枚集齐后 Boss 改掉落奖励分
- **相位冲刺（DASH）**：右下角独立按键，能量槽 2 格、每 2.4 秒回充一格；
  沿当前拖动方向高速相位位移 0.16 秒，位移与结束后短暂无敌帧可穿过弹幕，
  撞墙即停在边缘；冲刺路径留下舰影残像，HUD 用环形充能进度显示
- **LAB 金手指**：主菜单独立入口，可调初始生命（1-9）、道具掉率（50%-300%）、
  敌机速度（50%-200%）、初始火力（1-3）与无敌模式；参数持久化，生命/火力下一局生效，
  掉率/敌速/无敌即时生效，HUD 右上角显示 LAB 标记
- **擦弹充能 / OVERDRIVE**：敌弹擦身而过积攒 GRAZE 槽（同一颗弹只计一次），
  满槽自动清空敌弹并进入 5 秒过载：射速提升、火力临时 +1，HUD 左下显示充能进度
- **打击感反馈**：重甲与 Boss 击毁瞬间进入 hit-stop（全局模拟短暂缩至 22%，
  叠加一层冷白薄雾），连击越高屏幕四边辉光越亮
- **伤害飘字与暴击**：重击、暴击与击杀得分实时浮起淡出（暴击琥珀大号、得分金色大号，
  普伤小数字不刷屏，同帧最多 6 条并受低特效开关约束）；命中约 8% 概率触发 ×1.7 暴击，
  过载期间提升到 18%，结算数据卡新增暴击与 Boss 击破两项
- **点弹幕（截弹）**：单发伤害 ≥2 的重弹（导弹 / 集束 / 长枪 / 弹跳）撞上敌弹会把它引爆，
  穿透光束点爆后继续飞行，其余实弹与敌弹同归于尽；机炮（伤害 1）与僚机弹不参与，
  免得 Boss 的弹幕把主输出吃光。点掉一发 +2 分并计入 HUD 左下「截弹」计数，
  代价是这一发不再造成伤害、被点掉的敌弹也不再给擦弹充能——保命还是攒过载，自己选
- **冲刺弹反 PARRY**：相位冲刺本来就无敌，"躲掉一颗弹"是零收益、连擦弹都拿不到；
  现在冲刺路径上贴身的敌弹会被折返成一发伤害 3 的友军子弹（还会接着参与点弹幕），
  同一次冲刺里连反按 streak 倍率计分（15 / 30 / 45…），并补一点擦弹槽。
  折返弹保底拉到正常弹速，不会变成飘在半路的慢弹
- **随机异变波 MUTATOR**：打到 45 秒起，每隔一段随机开启 16 秒的全局异变——铁雨（敌机
  开火 ×1.9）、虫群（出怪 ×1.9、敌机血量 ×0.6）、钢铁洪流（血量 ×2.2、掉落 ×1.8）、
  疾行（敌速 ×1.4）、军火空投（掉落 ×3）、暴击临界（暴击率 ×3）、擦弹潮汐（擦弹充能 ×3），
  每一种都同时给这一段的所有得分加权（×1.25~1.6）：规则变狠但更值钱，扛过窗口还按
  期间的击坠数发一笔"异变平息"奖励。Boss 战里不再叠铁雨，免得两层弹幕糊成猜谜
- **终极技能 ULT（充能大招）**：击坠 / 精英 / 擦弹 / 点弹 / 弹反 / 吞弹 / 拆部件 / 杀 Boss
  全部汇进同一个槽（3 / 10 / 0.6 / 1 / 2 / 1.5 / 8 / 30 点），攒满 100 按右下角大招键释放。
  三档威力由**释放瞬间的槽量**决定（34 / 67 / 100 → 7 / 14 / 24 发光矛、伤害 4 / 6 / 8、
  时停 0.5 / 0.8 / 1.15 秒、无敌 1.0 / 1.6 / 2.4 秒），早点放和憋满放都是合法选择；
  光矛按离船距离排序逐个点名敌机与 Boss 部件、带穿甲，空场也朝天放空保证"按下一定有画面"。
  释放还会把满屏敌弹**折成伤害 3 的友军子弹**（与弹反同一套折返规则），
  槽满后继续战斗不浪费——溢出部分按每点 6 分直接折算进分数，硬核坠机只砍一半槽

## 项目结构
```
app/src/main/java/com/nebulastrike/game/
  core/     纯 Java 模拟层（不依赖 android.*）：实体、刷怪、碰撞、
            Boss AI、难度曲线、自适应画质调节器
  render/   Canvas 渲染器（900x1600 竖屏虚拟坐标系，任意屏幕自动留边适配），
            矢量图形零分配（共享 Path、缓存渐变）
  audio/    纯 Java 程序化音效合成（SfxBank）与 24 声部实时混音器（SfxMixer）
  AudioEngine  AudioTrack 流式播放 + 事件驱动音效调度（立体声/音高扰动/限流）
  Haptics  震动反馈
  GameView  游戏线程 + 触摸输入      MainActivity  入口
  UpdateManager  应用内升级（检查/下载/唤起系统安装器）  UpdateFileProvider  APK 只读提供器
  core/UpdateCheck  版本比较与发布 JSON 解析（纯逻辑，可单测）
app/src/test/   模拟层与音频合成 JUnit 单元测试（JVM 直接运行）
scripts/verify.sh   无 SDK 验证：类型检查 + 单元测试 + 模拟基准
```

## 性能
- 固定虚拟坐标系；所有实体走对象池；dt 钳位（后台恢复不会炸物理）
- 帧率调节器：游戏中 60 fps、菜单 30 fps；按帧耗时反馈自适应粒子发射量；
  低内存设备自动降特效
- `scripts/verify.sh` 第 4 步运行 60 秒最坏情况模拟基准
  （CI CPU 上约 5 微秒/帧 —— 相对 60 fps 预算有约 18 倍余量）

## 构建
```bash
./gradlew :app:assembleDebug     # debug APK 输出在 app/build/outputs/apk/debug/
./gradlew :app:assembleRelease   # 签名 release APK 输出在 app/build/outputs/apk/release/
```

release 使用仓库自带的密钥库 `release.keystore` 签名。密码**不写入仓库**，请放在
`local.properties`（已 gitignore）或环境变量里：

```properties
RELEASE_STORE_PASSWORD=你的密码
RELEASE_KEY_PASSWORD=你的密码
```

缺少密码时 `assembleRelease` 会直接失败，避免产出未签名 APK。仅供学习与自娱；
正式上架请更换为自己的密钥。

## 发版（一条命令）
```bash
DRY_RUN=1 scripts/release.sh 1.11.0 --notes /tmp/notes.md   # 只检查+构建+验签，不改动不推送
scripts/release.sh 1.11.0 --notes /tmp/notes.md             # 正式发版
scripts/release.sh 1.11.0                                   # 不传 --notes 时按提交记录自动生成正文
```
脚本依次完成：环境探测（JDK 17 / Android SDK / build-tools 34.x，macOS 与 Linux 通用）→
前置检查（工作树、tag 占用、版本号必须递增）→ 升 `versionName`/`versionCode` → `verify.sh` →
构建并验签 → 核对 APK 内版本号、证书 CN、大小与 SHA-256 → 提交打 tag 推送 `main` →
创建 Release 并上传 APK → 回验 `releases/latest` 指向并重新下载产物比对校验和。
Release 正文里的 `{{SHA256}}` 会被自动替换成真实校验和；任一步失败会自动还原
`app/build.gradle` 并删除本地 tag。`SKIP_VERIFY=1` 可跳过单测（仅在确认测试未受影响时使用）。
本机已 `gh auth login` 时不需要 token，否则用第 2 个参数或 `GITHUB_TOKEN`。
